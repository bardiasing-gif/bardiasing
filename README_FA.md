# BARDIA — وب‌سایت رسمی موسیقی بردیا

## شروع کار
1. فایل ZIP را از حالت فشرده خارج کن.
2. پوشه `BARDIA_Music_Site` را در VS Code باز کن.
3. فایل `index.html` را با مرورگر باز کن یا از افزونه Live Server استفاده کن.

## جایگزین کردن عکس
- عکس واقعی خودت را داخل `assets/images/` کپی کن.
- نام فایل را `bardia.jpg` بگذار.
- برای هر آهنگ، تصویر کاور را در همین پوشه قرار بده.

## اضافه کردن آهنگ واقعی
1. فایل MP3 را داخل `assets/music/` قرار بده؛ مثلاً `song-1.mp3`.
2. فایل `script.js` را باز کن.
3. در آرایه `songs`، عنوان، نام فایل، کاور و تاریخ را وارد یا اصلاح کن.

نمونه:
```js
{
  id: "song-4",
  title: "نام آهنگ جدید",
  cover: "assets/images/cover-4.jpg",
  file: "assets/music/song-4.mp3",
  date: "۱۴۰۵/۰۸/۲۰",
  category: "new"
}
```
شناسه `id` هر آهنگ باید یکتا باشد. برای دسته محبوب از `popular` و برای جدیدترین از `new` استفاده کن.

## انتشار روی GitHub Pages
تمام محتویات این پوشه را در مخزن GitHub خود آپلود کن. سپس در تنظیمات مخزن از بخش Pages، شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کن.

## نکته
این نسخه یک سایت استاتیک و خصوصی از نظر مدیریت محتوا نیست: هر کسی که نشانی سایت را داشته باشد می‌تواند آن را ببیند. برای پخش و دانلود، فایل‌های MP3 واقعی خودت را در پوشه `assets/music` قرار بده. فایل‌های صوتی نمونه عمداً داخل پروژه قرار نگرفته‌اند.


## اضافه کردن متن ترانه
برای هر آهنگ، ویژگی `lyrics` را در شیء همان آهنگ در فایل `script.js` قرار بده:
```js
{
  id: "song-4",
  title: "نام آهنگ جدید",
  cover: "assets/images/cover-4.jpg",
  file: "assets/music/song-4.mp3",
  date: "۱۴۰۵/۰۸/۲۰",
  category: "new",
  lyrics: `بیت اول ترانه
بیت دوم ترانه
بیت سوم ترانه`
}
```
متن ترانه در صفحه اختصاصی همان آهنگ نمایش داده می‌شود. برای حفظ خط‌بندی، از بک‌تیک استفاده کن.
